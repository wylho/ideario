# Protótipo de design (React + Radix)

Só referência visual e de comportamento. Não é a base de código do app.

- `App.tsx`: todas as telas (Notas, Lembretes, Arquivos, Moodboard, editor, gaveta, configurações).
- `data.ts`: dados de exemplo e o gerador das imagens SVG falsas.
- `index.css`: tokens de cor e tipografia (claro/escuro) e todos os estilos.
- `prototipo-empacotado.html`: versão em arquivo único, abre direto no navegador.

Foi criado com React 18, Vite, `@radix-ui/react-*` (dialog, select, popover, toggle-group, dropdown-menu, switch, slider) e `lucide-react`.
